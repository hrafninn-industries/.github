# Hrafninn Industries

Hrafninn Industries AB, in Kungsbacka, Sweden, builds websites, AI agents, and internal systems for companies. Daniel Merthen works alone, with Claude, GPT, Grok, Gemini, and local models on a DGX Spark.

Our first public repository, [claude-code-gates](https://github.com/hrafninn-industries/claude-code-gates), stops Claude Code before it spends money, deletes the wrong files or says "done" without proof. Free, MIT.
