# Hrafninn Industries

Hrafninn Industries AB, in Kungsbacka, Sweden, builds websites, AI agents, and internal systems for companies. Daniel Merthen works alone, with Claude, GPT, Grok, Gemini, and local models on a DGX Spark.

Our first public repository (29 September 2026) is [claude-code-gates](https://github.com/hrafninn-industries/claude-code-gates): MIT, free, Python 3.9+, no dependencies, 47 tests. Five checks run before a tool call in Claude Code. They cover paid image, video, and speech, batch commands, rm paths with a variable, `*`, or `~`, the most expensive model, and more than 10 sub-agents. `/spec` keeps acceptance criteria as true or false, and the verify script fails until each one has evidence. `check` asks a local model for a second opinion.
